2nd Largest
Given an array, return the second largest distinct number.

NOTE: Carefully notice distinct second_largest number means if

arr = [1, 0, -1, 0, 1, 0, -1, 1, 0]
then,
sorted_arr = [-1, -1, 0, 0, 0, 0, 1, 1, 1]

Now, in this case second_largest number = 1
But, second_largest distinct number is = 0
